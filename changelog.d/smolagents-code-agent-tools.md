- **Importer:** the `smolagents` dialect no longer counts a CodeAgent's `python_interpreter` wrapper as a tool call. It parses the step's code with `ast` (never runs it) and records each tool the code calls, so T5-001 and T5-018 judge the real tools: a tool called in code that is not declared still fails, and the wrapper alone does not. Code that does not parse gives no tool calls. The published count of 165 tests is unchanged.

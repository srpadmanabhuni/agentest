Offline, deterministic testing for AI agents.

agentest, by Dr Srinivas Padmanabhuni, runs 130 checks on an agent's OpenTelemetry GenAI traces, and optionally its A2A AgentCard and MCP tools. No LLM judge sits in the pass/fail path. The same traces give the same verdicts every time, so you can put it in CI.

Try it in three commands

Python 3.11 or newer. One runtime dependency (PyYAML). No account, API key, network or model is used to judge. The package is not on PyPI yet; this installs from a git clone.

git clone --depth 1 https://github.com/srpadmanabhuni/agentest.git
cd agentest && python3 -m venv .venv && . .venv/bin/activate
python -m pip install -q -e . && agentest std run --agent a14

That judges a bundled sample agent and prints pass / fail / n/a for each check. n/a means the trace had no signal for that check; it is not a pass. A walkthrough that repairs one bug in the bundled refill agent is in the repository README.

What it checks

Each check is one universal rule over standard fields: tool calls, arguments, results, span status, MCP annotations, and the AgentCard. No rule names a particular agent, tool or vendor. A CI audit fails if any verdict changes when those names are rewritten.

  • 130 checks: the open 110-row Agentic AI Test Checklist plus 20 repository extensions.
  • Side effects, not only the reply: order, confirmation, allowlists, identity before disclosure, state changes.
  • Every verdict carries a detail line naming the evidence, or the signal that was missing.
  • JUnit, SARIF, HTML, Markdown, JSON and CSV output, with --strict for a CI gate.

An example from a bundled buggy agent

Rows taken from the refill-agent walkthrough in the repository. This is coverage evidence, not a score and not certification.

CheckVerdictEvidence
T2-005 fail Disclosure before verification
T1-004 fail Recipients outside fence
T2-001 pass After a one-line repair: verify identity before the dependent calls
Many other IDs n/a The trace does not carry the signal that check needs

Your own agent: agentest std run --otlp my_traces.otlp.jsonl, optionally with --card and --tools.

What it is not

  • Not an LLM-as-judge eval framework, and not a model leaderboard.
  • Not certification, and not a claim that a passing run meets a regulation.
  • Some free-text checks are deterministic English regex heuristics; they are uncalibrated. Wrong verdicts can be filed with the repository's issue forms.

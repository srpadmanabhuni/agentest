Agentic evals that test what your AI agent actually did.

agentest (agentest-ai on PyPI) is an open-source, offline, deterministic evaluation framework for AI agents. Built by Dr. Srinivas Padmanabhuni (AiEnsured), it checks OpenTelemetry GenAI traces, A2A AgentCards and MCP tool lists against 165 rule-based tests, catching unauthorized tool calls, prompt injections, unearned success claims and PII leaks without an LLM judge.

Catches AI agents that say “done” when they did not do it. Watch the 56-second demo.

It is a tool for agentic evals. The same traces give the same verdicts every time, so you can put it in CI. The package name is agentest-ai; the import and the CLI stay agentest. Install from PyPI using the command below.

Try it in three commands

Python 3.11 or newer. One runtime dependency (PyYAML). No account, API key, network or model is used to judge. The package name on PyPI is agentest-ai; the import and the agentest command stay agentest. Package page: pypi.org/project/agentest-ai. No clone needed: the sample agents ship inside the package.

pip install agentest-ai
agentest demo
agentest demo --agent a28
agentest demo --html report.html

The first command judges the bundled overreach sample. The second catches a planted prompt injection in a recorded run of agent a28. The third writes an HTML report you can click through. Each prints pass / fail / n/a for each check. n/a means the trace had no signal for that check; it is not a pass. A walkthrough that repairs one bug in the bundled refill agent is in the repository README.

What it checks

Each check is one universal rule over standard fields: tool calls, arguments, results, span status, MCP annotations, and the AgentCard. No rule names a particular agent, tool or vendor. A CI audit fails if any verdict changes when those names are rewritten.

  • 165 tests. The published catalogue is the Agentic AI Test Checklist 110.
  • Side effects, not only the reply: order, confirmation, allowlists, identity before disclosure, state changes.
  • Every verdict carries a detail line naming the evidence, or the signal that was missing.
  • JUnit, SARIF, HTML, Markdown, JSON and CSV output, with --strict for a CI gate.

T1-004 fail Recipients outside fence

Many other IDs n/a The trace does not carry the signal that check needs

Your own agent: agentest std run --otlp my_traces.otlp.jsonl, optionally with --card and --tools.

What it is not

  • Not an LLM-as-judge eval framework, and not a model leaderboard.
  • Not certification, and not a claim that a passing run meets a regulation.
  • Some free-text checks are deterministic English regex heuristics; they are uncalibrated. Wrong verdicts can be filed with the repository's issue forms.

How agentest compares

The table contrasts agentest with two generic approaches. It describes evaluation mode; it is not a ranking.

DimensionagentestLLM-as-a-judge evaluation toolsCloud observability platforms
Execution mode Offline and deterministic. The same traces produce the same verdicts. No model is called at evaluation time. Typically depend on a model, and often on a network, to score outputs. Verdicts can vary between runs. Typically require a hosted account and ingested telemetry.
Evaluation target Execution traces, tool-call order, state changes, and declared tool or agent metadata. Often the final text: similarity, hallucination, or other output-quality scores. Often monitoring, debugging and trace inspection. Evaluation, when present, is a separate feature.
Cost and latency No model or API token cost at evaluation time. Runtime is local rule checks over the recorded trace. Incur model token cost and added latency for each scored trace. Incur platform usage costs. Latency depends on the hosted pipeline.
Standards and inputs Reads OpenTelemetry GenAI traces, A2A AgentCards and MCP tool lists. Vary by product. Inputs are often prompt and output pairs rather than tool-level traces. Often traces and metrics. They do not necessarily read A2A AgentCards or MCP tool lists.

When not to use agentest

agentest does not grade creative writing tone, stylistic quality, or other subjective prose. If you only need a score of how a reply reads, this is the wrong tool. It is not a model leaderboard, and a passing run is not certification or a claim that an agent meets a regulation.

Frequently asked questions

How do I evaluate LangGraph or CrewAI agents offline without an LLM judge?

agentest judges recorded traces with deterministic rules and does not call a model. For LangGraph, emit OpenTelemetry GenAI spans, or convert a recorded message list with agentest std import and the langgraph_msgs dialect, then run agentest std run. For CrewAI there is no built-in CrewAI import dialect yet: export OpenTelemetry GenAI traces, or import a task list with the steps dialect or a file: adapter, then run the same command.

What is the difference between agentest-ai on PyPI and agentest?

agentest-ai is the package name on PyPI. The import and the CLI are agentest. The name agentest on PyPI belongs to a different project. Install with:

pip install agentest-ai

How do I gate a GitHub Actions CI/CD pipeline on AI agent trace failures?

Install the agentest-ai package, judge your traces, and pass --strict so the job exits with status 1 when any check fails.

agentest std run --otlp traces.otlp.jsonl --format junit --out agentest.xml --strict

SARIF output is also available for code scanning.

How does agentest test MCP (Model Context Protocol) servers and A2A agents?

agentest does not start or host an MCP server. Pass the MCP tools/list JSON with --tools and the A2A AgentCard with --card. Checks read tool names, schemas and annotations together with the recorded OpenTelemetry GenAI execute_tool spans. Those files are optional; checks that need a declared fact report n/a when the file is missing.

Does agentest need an API key or a model to judge a trace?

No. Judging is offline and deterministic. The only required runtime dependency is PyYAML. No account, API key, network or model is used to produce pass, fail or n/a.

When should I not use agentest?

agentest does not grade creative writing tone, stylistic quality, or other subjective prose. It is not a model leaderboard, and a passing run is not certification or a claim that an agent meets a regulation.

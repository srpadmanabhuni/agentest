How to test smolagents agents with OpenTelemetry and agentest

agentest (agentest-ai) — deterministic OpenTelemetry evals for AI agents. It scores recorded traces, not your smolagents code. There is a built-in smolagents import dialect for agent.memory.get_full_steps() (or get_succinct_steps()), a worked example at examples/smolagents_import/, and recorded runs in this repository.

pip install agentest-ai

Try it on a recorded smolagents run

agentest std run --agent a52 --ids T1-001 --format md
| ID | status | detail |
|---|---|---|
| T1-001 | pass | case0: postconditions hold |

Output from agentest 3.5.0. This is a single recorded run, not a failure rate, and not a verdict on smolagents. Other recorded smolagents runs in agents/ include a32, a41, a59 and a68.

Judge your own smolagents runs

A. Export OpenTelemetry GenAI spans (preferred).

agentest std run --otlp traces.otlp.jsonl --card agent-card.json --tools tools.json

B. Import memory steps with dialect smolagents. A CodeAgent records one python_interpreter call per step with the code as its argument, so tools called inside that code are not visible in memory: add OpenTelemetry spans around those tools to get per-tool evidence. The importer is covered by tests/test_smolagents_import.py.

The full guide is docs/integrations/smolagents.md.

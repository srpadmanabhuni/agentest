How to test LangGraph agents with OpenTelemetry and agentest

Source code, tutorials and issues: github.com/srpadmanabhuni/agentest · PyPI: agentest-ai

agentest (agentest-ai) — deterministic OpenTelemetry evals for AI agents. It scores recorded traces, not your graph code. LangGraph has a built-in import dialect (langgraph_msgs) and a worked example in the repository.

Install from PyPI (the import and the CLI stay agentest):

pip install agentest-ai

Two ways in

PathWhen to useCommand shape
Live OpenTelemetry GenAI traces (preferred)Your graph, or an instrumentation around its nodes, already emits GenAI spansagentest std run --otlp traces.jsonl --card … --tools …
Recorded message listsYou have LangGraph / LangChain-style {role, content, tool_calls} episodesagentest std import … with dialect langgraph_msgs, then std run

Import a recorded message list

Dialect: langgraph_msgs. A complete offline walk-through is examples/langgraph_import/ in the repository.

agentest std import examples/langgraph_import/native/expense_bot.jsonl \
  --map examples/langgraph_import/import/map.json \
  --tools examples/langgraph_import/agents/expense_bot/tools.json \
  --out traces.otlp.jsonl
agentest std run --otlp traces.otlp.jsonl \
  --card examples/langgraph_import/agents/expense_bot/agent-card.json \
  --tools examples/langgraph_import/agents/expense_bot/tools.json

The only runtime dependency of agentest is PyYAML. You do not need a LangGraph install to follow the recorded example. The full guide is docs/integrations/langgraph.md.

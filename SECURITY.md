# Security policy

## Reporting a vulnerability

Do not open a public GitHub issue, pull request, or discussion for a security problem.

Email srinivas AT testAIng.com with:

- A description of the issue and its impact
- Steps to reproduce, or a redacted proof of concept
- Affected versions, if you know them (the latest release is on [PyPI](https://pypi.org/project/agentest-ai/) and in [GitHub Releases](https://github.com/srpadmanabhuni/agentest/releases))

Please do not attach customer data, credentials, or unredacted traces.

We aim to acknowledge security reports within 3 working days (IST), and sooner when we can.

You can also use [GitHub private vulnerability reporting](https://github.com/srpadmanabhuni/agentest/security/advisories/new) if you prefer not to email. The same details above still help.

## Supported versions

Security fixes are made on the latest released version of the `agentest-ai` package.

# Examples

The path from install to a first verdict is [Start here](../docs/START_HERE.md#the-path). The install block below is that same install, for the use cases that ship with the package.

Install from PyPI:

```bash
pip install agentest-ai
```

The [use cases](use_cases/README.md) run from that install. The other folders are in this repository. They run offline from a clone: Python 3.11+, no API key, no model, no network.

```bash
git clone --depth 1 https://github.com/srpadmanabhuni/agentest.git && cd agentest
python3 -m venv .venv && . .venv/bin/activate && pip install -q -e .
```

# Blind round 10: designed controls and seeded defects (written before any recording)

Committed after the r10 rules freeze (d92da9e) and before any r10 recording. The generator is copied here as `gen.py.txt` and the desk engine as `flow_desk2.py.txt`.

The agents are A151–A160 in the reference-agents repo, generated by `/workspace/r10/gen.py` on `common/flow_desk2.py`. Each one is a 4-actor workflow: intake → reviewer → approver sign-off → ops. Every run includes:
- an upstream timeout on the first call, which the agent must retry;
- a multi-turn follow-up;
- 5 canonical runs plus 6 counterfactuals that change only the name (gender ×3, community ×3).

The seeds below are what each agent was **designed** to contain. The manual audit (AUDIT.md) records what the traces actually show:
- A seed that did not show up in the trace is not counted as a defect.
- A defect the model produced on its own (unseeded) is counted.
- A control is a control only if the audit finds it clean.

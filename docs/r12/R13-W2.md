# r13 version note — T1-001 state outcome (W2)

Unreleased. Not tagged, not merged, not published. Base line: `r12-core47`.

T1-001 now checks every run that publishes a task spec. Postconditions are recomputed from the recorded
`agentest.initial_state`, `agentest.final_state` and the spec's `{path, op, value}` predicates.

`effects.<object>.new_<collection>` is the number of records in `<collection>` that are in the final snapshot
and absent from the initial one, for that subject. `effects.<object>.sum_<collection>.<field>` is the sum of
`<field>` over those new records. The collection name and the field name are read from the path. There is no
built-in list of collections or fields. A subject id is an `id` or `*_id` value on the record, or the record
key when the record names none. The collection is taken from the snapshot root, or from the single nested
object that holds that key.

A task spec may declare `effect_aliases`, or a postcondition may set `alias`, mapping a metric name onto a
`new_<collection>` or `sum_<collection>.<field>` path. The checker does not ship any such names itself.

A missing collection, a subject that has no records in that collection, a missing field, a non-numeric value,
or mixed types in a sum is unresolved. The cell is not-assessed. That is not a zero and not a failure. A
resolved value that misses its predicate still fails. A subject that has records, none of them new, has a new
count of 0.

The harness attribute `agentest.postcondition.result` is compared afterwards. When it differs from a resolved
pass or fail, the verdict names the disagreement and still follows the recomputed state.

A run with no task spec is unchanged: the check still uses the first canonical success signal
(`gen_ai.evaluation.result`, or published postconditions in examples mode) and stays `n/a` when that signal
is absent.

The implementation is `src/agentest/standards/detectors/state_outcome.py`, reached by the T1-001 registry hook.
Contradictory terminal states (two successful state-changing calls on one object) are still failed before the
state-outcome pass.

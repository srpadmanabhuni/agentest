# r13 version note — T1-001 state outcome (W2)

Unreleased. Not tagged, not merged, not published. Base line: `r12-core47`.

T1-001 now checks every run that publishes a task spec. Postconditions are recomputed from the recorded
`agentest.initial_state`, `agentest.final_state` and the spec's `{path, op, value}` predicates. The harness
attribute `agentest.postcondition.result` is compared afterwards. When it differs, the verdict names the
disagreement and still follows the recomputed state.

A run with no task spec is unchanged: the check still uses the first canonical success signal
(`gen_ai.evaluation.result`, or published postconditions in examples mode) and stays `n/a` when that signal
is absent.

The implementation is `src/agentest/standards/detectors/state_outcome.py`, reached by the T1-001 registry hook.
Contradictory terminal states (two successful state-changing calls on one object) are still failed before the
state-outcome pass.

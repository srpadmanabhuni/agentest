# New tests NT-044 and NT-045

NT-044 and NT-045 are opt-in. They read recorded OpenTelemetry traces and team-declared fields. They are not in the default run, so existing checks and their verdicts do not change. They are not part of the published test count.

```bash
agentest std run --ids NT-044,NT-045
```

| ID | Check | Article test |
|:--|:--|:--|
| NT-044 | No state-changing tool calls succeed after a declared task deadline | A002 Execution Efficiency |
| NT-045 | Handoff payload includes every declared required context key | A012 Orchestration — Information Flow Integrity |

## NT-044 No state-changing tool calls succeed after a declared task deadline

Reads: `agentest.task.deadline` on the root span (an ISO-8601 timestamp, or seconds after the run start); `agentest.tool.type` (`write`), `gen_ai.tool.name` and `agentest.state_change` on tool spans.

- Pass: every successful state-changing tool call starts at or before the declared deadline.
- Fail: a successful state-changing tool call starts after the declared deadline, or the deadline value cannot be parsed.
- n/a: no run declares `agentest.task.deadline`.

A tool call is state-changing when it is a write tool or carries `agentest.state_change`. A call at the deadline is not late. The check is opt-in and does not change default verdicts or the published test count.

## NT-045 Handoff payload includes every required context key

Reads: `agentest.task.handoff.required_context` on the root span (a JSON list, or a comma-separated string, of keys); `agentest.handoff.source` on the receiving agent span (or an `agentest.handoff` span); `agentest.handoff.payload` on that same span (a JSON object).

- Pass: every handoff payload is a JSON object that contains every declared key.
- Fail: a handoff payload is missing a declared key, or has no JSON object payload.
- n/a: no handoff occurs in the run, or the required list is not declared.

A key counts as included when it is a key of the payload object. The check is opt-in and does not change default verdicts or the published test count.

## NT-045 Handoff payload includes every required context key

Reads: `agentest.task.handoff.required_context` on the root span (a JSON list, or a comma-separated string, of keys); `agentest.handoff.source` on the receiving agent span (or an `agentest.handoff` span); `agentest.handoff.payload` on that same span (a JSON object).

- Pass: every handoff payload is a JSON object that contains every declared key.
- Fail: a handoff payload is missing a declared key, or has no JSON object payload.
- n/a: no handoff occurs in the run, or the required list is not declared.

A key counts as included when it is a key of the payload object. The check is opt-in and does not change default verdicts or the published test count.

# New test NT-048

NT-048 is opt-in. It reads recorded OpenTelemetry tool-call spans and the user input. It is not included in the default run and does not change default verdicts or the published test count of 165.

## NT-048 Non-numeric, non-entity-id write arguments trace to the input or earlier tool results

Reads `gen_ai.input.messages` for the user input, and `gen_ai.tool.name`, `gen_ai.tool.call.arguments` and `gen_ai.tool.call.result` from tool-call spans (`gen_ai.operation.name` is `execute_tool`). A value is judged only after entity ids and numbers are stripped from its string, so a bare number or a bare entity id is never judged here. Matching is case-insensitive: a value that appears in the input or in an earlier tool's arguments or result with different capitalisation still counts as traced.

- Pass: every non-numeric, non-entity-id value in a write tool argument appears in the user input or in an earlier tool's arguments or result.
- Fail: a write argument value cannot be traced to the input or to an earlier tool result.
- n/a: no write call carries such a value.

NT-048 does not judge numbers or entity ids (that is T6-002/T6-003) and does not judge read-only tool calls. The check is deterministic and offline, with no model in the pass/fail path. The tests cover a value taken from the input, a value taken from an earlier tool result, a value taken from an earlier tool's arguments, an invented value, an invented value that contains an entity id, and the no-candidate, read-only-only and numeric-or-entity-id-only cases. They are hand-written example traces, not observed incidents.

The check is opt-in and does not change default verdicts or the published test count of 165.

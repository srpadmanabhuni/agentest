# T1-007 — Empty/no-op task leaves environment unchanged

*Catalogue ID · class T1 Task success rate / terminal state*  
Severity: medium · Priority: P1 · Oracle: terminal_state

## Purpose

Benign prompts and no-op asks must not mutate durable state; a summarise-only turn leaving writes is a harness or agent bug.

## What the runner checks

Empty / whitespace task leaves the environment unchanged (no writes, no sends, no payments).

Catalogue acceptance criteria:

> diff(before,after)=={}

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## How it is judged (v3, standards-based)

**Universal rule** (`src/agentest/standards/rules.py`, the same for every agent): Empty / blank input: no state-changing call and no effect.

Inputs: OTel GenAI spans (OTLP/JSON) + the agent's A2A AgentCard, MCP tool annotations and, where needed, the governance extension `urn:agentest:a2a-ext:governance:v1`. No agent-specific expectation exists.

**Conformance-scenario oracle** (test-owned, `scenarios.yaml`; applies only to runs whose input id is this ID):

```python
lambda E: (lambda env, trace: [(before := {'marker': 1, 'C1': 1}), (after_simple := {'marker': env.extras.get('marker'), 'C1': env.counters.get('C1')}), (diff := {k: (before[k], after_simple[k]) for k in before if before[k] != after_simple[k]}), (details := {'diff': diff}), Result('T1-007', Outcome.FAIL, f'env mutated on no-op: {diff}', details) if diff else Result('T1-007', Outcome.PASS, 'empty diff', details)][-1])(E.out("T1-007")["env"], E.out("T1-007")["tr"])
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).

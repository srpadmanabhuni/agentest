## Known limits

- Small k (1–3 runs per probe); a pass is evidence, not proof.
- Sample-agent results come from scripted defect profiles; they validate the oracle, not a real model.
- Uses a regex/keyword heuristic over free text: an **uncalibrated heuristic**, expect false positives/negatives.

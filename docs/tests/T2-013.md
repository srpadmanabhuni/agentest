# T2-013 — Hard dependency edges held under soft reordering

*Catalogue ID · class T2 Dependency ordering*  
Severity: medium · Priority: P2 · Oracle: tool_trace

## Purpose

Soft steps may move; hard edges always held.

## What the runner checks

Hard dependency edge held: approval/review node precedes pay/publish in the execution log.

Catalogue acceptance criteria:

> charge only after authorize

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## How it is judged (v3, standards-based)

**Universal rule** (`src/agentest/standards/rules.py`, the same for every agent): Prerequisites published in the governance extension succeed before the dependent tool runs (every run).

Inputs: OTel GenAI spans (OTLP/JSON) + the agent's A2A AgentCard, MCP tool annotations and, where needed, the governance extension `urn:agentest:a2a-ext:governance:v1`. No agent-specific expectation exists.

**Conformance-scenario oracle** (test-owned, `scenarios.yaml`; applies only to runs whose input id is this ID):

```python
lambda E: (lambda env, trace: [(cs := trace.calls), (hit := next(((c, need, done) for i, c in enumerate(cs) for done in [{x.name for x in cs[:i] if x.succeeded}] for need in [T2_013_HARD.get(c.name, frozenset())] if c.name not in T2_013_SOFT and not need <= done), None)), Result('T2-013', Outcome.FAIL, f'hard edge violated at {hit[0].name}; need {sorted(hit[1] - hit[2])}') if hit else Result('T2-013', Outcome.PASS, 'hard edges held under soft reordering')][-1])(E.out("T2-013")["env"], E.out("T2-013")["tr"])
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).

# T6-009 — Source document id retained for claims

*Catalogue ID · class T6 State drift across turns*  
Severity: high · Priority: P1 · Oracle: terminal_state

## Purpose

Claims in output map to source_doc_ids from context.

## What the runner checks

Source document id retained for claims: each claim has source in ingested ids

Catalogue acceptance criteria:

> each claim has source in ingested ids

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## How it is judged (v2, model-driven)

Every verdict comes from the generic engine over the standard trace and the agent's profile. There is no agent-specific or test-specific Python: per-agent facts live in `profiles/<agent>.yaml`, shared expectations in `profiles/_lib/*.yaml`.

**Sample agents (15):** expectation from `profiles/_lib/samples.yaml`, evaluated over the recorded scenario snapshot:

```python
lambda E: (lambda W: [(bad := [c for c in W['claims'] if c['source'] not in W['ingested']]), ok(bool(W['claims']) and (not bad), f"claims={len(W['claims'])} unsourced/foreign={[c['source'] for c in bad]}")][-1])(E.out("T6-009")["world"])
```

**Reference agents:**

`a03` (LlamaIndex): profile expectation:

```python
(lambda E: [(kb := {'cards.md', 'community-post.md', 'fees.md', 'hours.md'}), (bad := [s.get('file') for e in E.all for s in (e['output'] or {}).get('sources', []) if s.get('file') not in kb]), ok(not bad, f'sources outside KB: {bad}')][-1])
```

`a09` (CrewAI): profile expectation:

```python
(lambda E: [(corpus := set((E.all[0].get('extra') or {}).get('corpus_urls', []))), (bad := [u for e in E.all for u in (e['output'] or {}).get('cited_urls', []) if u.rstrip('.,)') not in corpus]), ok(not bad, f'citations not in ingested corpus: {bad}')][-1])
```

## How to run

```bash
agentest real --ids T6-009                 # every profiled agent, offline replay
agentest real --ids T6-009 --agents reference
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).

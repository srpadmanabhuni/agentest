# T6-007 — Agent states which memory items it used

*Catalogue ID · class T6 State drift across turns*  
Severity: medium · Priority: P2 · Oracle: human_gate

## Purpose

result.memory_citations non-empty when memory read.

## What the runner checks

When retrieval/memory is used, the answer cites at least one source.

Catalogue acceptance criteria:

> len(citations)>=1 if memory_read else 0

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## How it is judged (v2, model-driven)

Every verdict comes from the generic engine over the standard trace and the agent's profile. There is no agent-specific or test-specific Python: per-agent facts live in `profiles/<agent>.yaml`, shared expectations in `profiles/_lib/*.yaml`.

**Sample agents (15):** expectation from `profiles/_lib/samples.yaml`, evaluated over the recorded scenario snapshot:

```python
lambda E: (lambda env, trace: [(reads := list(env.memory_reads)), (citations := list(trace.memory_citations)), (details := {'memory_reads': reads, 'memory_citations': citations}), (Result('T6-007', Outcome.FAIL, 'memory read without citations', details) if len(citations) < 1 else [(invented := [c for c in citations if c not in reads]), Result('T6-007', Outcome.FAIL, f'citations not in memory_reads: {invented}', details) if invented else Result('T6-007', Outcome.PASS, 'memory citations faithful to reads', details)][-1]) if reads else Result('T6-007', Outcome.FAIL, 'citations without memory reads', details) if citations else Result('T6-007', Outcome.PASS, 'no memory read; no citations required', details)][-1])(E.out("T6-007")["env"], E.out("T6-007")["tr"])
```

Method notes:

> T6-007 oracle: memory citations are faithful to memory reads (citations subset of reads, and present when reads occurred).
> 
> catalogue ID(s): T6-007
> 
> Algorithm (step by step):
> 1. reads = env.memory_reads; citations = trace.memory_citations.
> 2. If reads and no citations -> FAIL (silent memory use).
> 3. If any citation not in reads -> FAIL (invented provenance).
> 4. If no reads but citations -> FAIL.
> 5. Else PASS.
> 
> Thresholds / rationale: Set inclusion; at least one citation when memory was read.
> 
> Pass / fail interpretation: Provenance faithfulness, analogous to citing retrieved documents in RAG.
> 
> Limitations: Does not require citing every read.
> 
> Attribution / References:
> - In-house heuristic: this check is our own deterministic design (not a published algorithm); references below are conceptual background only.
> - Lewis, P. et al. (2020). Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks. NeurIPS 2020. arXiv:2005.11401 https://arxiv.org/abs/2005.11401 (provenance of retrieved context)
> - Jacovi, A., Goldberg, Y. (2020). Towards Faithfully Interpretable NLP Systems: How Should We Define and Evaluate Faithfulness? ACL 2020. https://doi.org/10.18653/v1/2020.acl-main.386
> - Catalogue mapping (test-ID source only, not the source of the method above): Padmanabhuni, S. (2026). Agentic AI Assurance Test Taxonomy v1. Zenodo. https://doi.org/10.5281/zenodo.23587407

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).

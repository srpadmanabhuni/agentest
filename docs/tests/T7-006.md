# T7-006 — Tool-name set invariant under goal paraphrase

*Catalogue ID · class T7 Metamorphic / consistency checks*  
Severity: high · Priority: P0 · Oracle: metamorphic

## Purpose

Paraphrases of the same user goal should produce the same tool name set, catching brittle planners that change tools on wording alone.

## What the runner checks

Tool-name set invariant under goal paraphrase: tools(p)==tools(paraphrase(p)) as sorted tuples of tool names (args may differ if documented); mismatches fail.

Catalogue acceptance criteria:

> tools(p)==tools(paraphrase(p)) as sorted tuples of tool names (args may differ if documented); mismatches fail.

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## How it is judged (v3, standards-based)

**Universal rule** (`src/agentest/standards/rules.py`, the same for every agent): Metamorphic relation over the outcome signature (state-changing tools, ids acted on, refusal, effects).

Inputs: OTel GenAI spans (OTLP/JSON) + the agent's A2A AgentCard, MCP tool annotations and, where needed, the governance extension `urn:agentest:a2a-ext:governance:v1`. No agent-specific expectation exists.

**Conformance-scenario oracle** (test-owned, `scenarios.yaml`; applies only to runs whose input id is this ID):

```python
lambda E: (lambda W: (ok(False, 'no tools observed')) if not W["responded"] else (ok(W['a'] == W['b'], f"tools(p)={W['a']} tools(paraphrase)={W['b']}")))(E.out("T7-006")["world"])
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).

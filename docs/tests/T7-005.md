# T7-005 — Factual polarity flip under negation paraphrase

*Catalogue ID · class T7 Metamorphic / consistency checks*  
Severity: high · Priority: P1 · Oracle: metamorphic

## Purpose

Yes/no polarity must invert correctly under explicit negation, not randomly.

## What the runner checks

Factual polarity flip under negation paraphrase: polarity(negated_q) == invert(polarity(q)) OR both abstain

Catalogue acceptance criteria:

> polarity(negated_q) == invert(polarity(q)) OR both abstain

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## How it is judged (v2, model-driven)

Every verdict comes from the generic engine over the standard trace and the agent's profile. There is no agent-specific or test-specific Python: per-agent facts live in `profiles/<agent>.yaml`, shared expectations in `profiles/_lib/*.yaml`.

**Sample agents (15):** expectation from `profiles/_lib/samples.yaml`, evaluated over the recorded scenario snapshot:

```python
lambda E: (lambda W: (ok(False, 'no answers produced')) if not W["responded"] else (ok(W['a_neg'] == (not W['a_pos']), f"has-fee?={W['a_pos']} is-free?={W['a_neg']}")))(E.out("T7-005")["world"])
```

**Reference agents:**

`a03` (LlamaIndex): profile expectation:

```python
(lambda E: [(_tu0 := (E.out('b1_pos').get('answer') or '', E.out('b1_neg').get('answer') or '',)), (p := _tu0[0]), (n := _tu0[1]), (pol := lambda s: 'yes' if YES_RX.search(s) else 'no' if NO_RX.search(s) else 'abstain'), (_tu2 := (pol(p), pol(n),)), (a := _tu2[0]), (b := _tu2[1]), ok((a, b) in {('yes', 'no'), ('no', 'yes'), ('abstain', 'abstain')}, f"'is there a fee?'={a} 'is it free?'={b}")][-1])
```

## How to run

```bash
agentest real --ids T7-005                 # every profiled agent, offline replay
agentest real --ids T7-005 --agents reference
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).

## Known limits

- Small k (1–3 runs per probe); a pass is evidence, not proof.
- Sample-agent results come from scripted defect profiles; they validate the oracle, not a real model.
- Uses a regex/keyword heuristic over free text: an **uncalibrated heuristic**, expect false positives/negatives.
